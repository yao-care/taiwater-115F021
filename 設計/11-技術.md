
## 共用 React 元件清單

### Layout
- `<AppHeader>` Header 含搜尋/區處/通知/角色快切
- `<AppNav>` 動態 nav（依角色 filter）
- `<AppShell>` Header + Nav + Main 三段式
- `<PageHeader>` 頁面標題 + 麵包屑 + RFP 追溯

### 表單
- `<FormGrid cols={2}>` form grid 容器
- `<FormRow label="" required>` 一列
- `<FormInput type="" />` 含 focus 樣式
- `<FormSelect options={[]} />` 下拉

### 數據展示
- `<KpiCard value="" label="" delta="" />` KPI 卡片
- `<Table headers={[]} rows={[]} />` 通用表
- `<Badge type="critical" />` 嚴重度
- `<StatusDot color="green" />` 狀態點
- `<Timeline items={[]} />` 時間軸

### 業務元件（**重點：共用後連動修改！**）
- `<CaseCard case={} />` 案件卡（連動：列表/地圖/詳情都用同一份 case data）
- `<CaseStatusFlow case={} />` 案件流程圖（status timeline）
- `<DispatchBoard />` 派工看板（拖拉式）
- `<GisMap layers={} markers={} />` GIS 地圖（含 WMTS/WMS toggle）
- `<RiskChart pipes={} />` 風險評分圖
- `<NotificationBell count={} items={} />` 通知鈴鐺
- `<RoleSwitcher current={} options={} />` 角色快切
- `<IntegrationStatus systems={} />` 介接系統健康度
- `<ComplianceMatrix domains={} />` 資安合規矩陣
- `<DocumentList docs={} />` 文件清單
- `<AuditLog entries={} />` 稽核日誌

### 行動版元件
- `<PhoneFrame>` 360×720
- `<MobileStatusBar />` 09:42 信號電池
- `<MobileAppBar title back />` 標題列
- `<MobileTabBar tabs={} active={} />` 底部 4 tab
- `<MobileListItem case={} />` 任務卡
- `<MobileButton primary>` 大按鈕
- `<MobilePhotoGrid photos={} max={9} />` 照片格

## 元件連動範例（呼應原則 2）

```jsx
// 同一份 case data，三個地方共用
function App() {
  const { state } = useContext(StoreContext);

  return (
    <>
      {/* 1. 地圖上的點 */}
      <GisMap markers={state.cases} />

      {/* 2. 列表頁 */}
      <CaseList cases={state.cases} />

      {/* 3. 通知中心 */}
      <NotificationBell items={state.cases.filter(c => c.urgent)} />
    </>
  );
}

// 任一處改了 case.status，三個地方同時 re-render
dispatch({ type: 'UPDATE_CASE', payload: { id, status: 'closed' } });
```
