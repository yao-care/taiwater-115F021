# 07 — 7 條可玩流程

每條流程承辦可從任一切入點開始玩，所有資料即時連動。

## 流程 A：案件生命週期（核心 demo）

跨 5 角色 12 步驟：

```
1. 客服 蔡美玲     收到電話 → [+ 新案件 一鍵]      → 案件成立
2. 客服            自動帶 GPS、推派廠所、通知       → 通知中港廠
3. 廠所 賴伯毅     紅點 +1 → 打開派工看板           → 看到新案
4. 廠所            [一鍵派工→王志強]               → 通知檢漏員
5. 檢漏員 王志強   行動版任務 +1 → 點開            → 進案件詳情
6. 檢漏員          [拍照] [GPS] [一鍵上傳]         → 案件 status=確認漏水
7. 廠所            [派修漏員→林文雄 一鍵]          → 通知修漏員
8. 修漏員 林文雄   行動版任務 +1 → 開始修復        → 進實修登錄
9. 修漏員          [一鍵結案]（自動算漏水量/費用）→ 回填客服
10. 客服           [自動知會用戶]                  → SLA 達標 +1
11. 區處主管       Dashboard KPI 即時更新          → 月報 +1 件
12. 總處           全國儀表板 +1                   → 達成率重算
```

**承辦演示**：在不同分頁切角色，看到資料同步更新。

## 流程 B：行動版檢漏員一日（純行動版）

```
1. 早 8:30  打開行動版 → 看到今日 5 件待處理（依距離排序）
2. 9:00     點第一件 → [導航] → Google Maps 開啟
3. 9:30     到現場 → [拍照 ×3] → 自動 EXIF GPS
4. 9:35     [GPS 定位] → WGS84 + TWD97 雙坐標
5. 9:40     選漏水情形 → [送出案件] → 完成
6. 11:00    繼續下一件...
7. 17:00    [產生今日工作日報 一鍵] → 結束
```

## 流程 C：廠所派工管理

```
1. 賴伯毅打開派工看板（4 個 column）
2. 拖拉案件「未派工 → 派工中」→ 自動帶最近檢漏員
3. 點「批次派工」→ 圈選 3 件 → 派同一檢漏員
4. 點「查看派工歷史」→ 過去 30 天甘特圖
```

## 流程 D：年度成果報告書

```
1. 區處主管打開「年度報告書中心」
2. 系統自動產生 16 章內容（從 store.cases + store.repairs 算）
3. 主管逐章審核，可手動編修
4. [一鍵匯出 ODF] → 下載 .odt 檔
5. [送總處核發] → 流程結束
```

## 流程 E：PCCES 預算書編製

```
1. 廠所人員打開「工程預算書」
2. 選一個高金額修漏案（> 1000 萬警示出現）
3. 系統建議工項 → 自動帶工程會細目編碼
4. 顯示「編碼正確率 83% ✓ 通過 40% 門檻」
5. [預覽 XML] → 5 步驟 wizard
6. [上傳工程會 PCCES 平台] → 完成
```

## 流程 F：資安合規檢核

```
1. 資安人員打開「資安合規矩陣」
2. 看 8 構面 127 控制措施 progress bar
3. 點「存取控制」展開 → 看 28 項細項狀態
4. 看到「Session 自動登出」未實作 → 點「改善追蹤」
5. 內稽員從另一視窗看到同一份矩陣（唯讀）
6. 外稽員（ISO 27001 LA）匯出稽核報告
```

## 流程 G：介接系統管理

```
1. 系統管理員打開「介接管理」
2. 看 14 個系統健康度 dashboard
3. 看到「新北消防局」⚠ 黃燈 → 點開
4. 看延遲歷史圖、最近錯誤 log
5. [手動同步] → 一鍵重試
6. 設定「自動告警閾值」
```
