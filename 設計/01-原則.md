# 01 — 核心 5 原則

| # | 原則 | 設計對應 |
|---|------|---------|
| 1 | 10 帳號下拉直達 | 點選帳號直接進該角色 dashboard，不需打密碼。「真實演示」模式才觸發完整 AD + 雙因素 |
| 2 | 元件連動修改 | React Context + useReducer + localStorage。改 A 角色資料，B 角色頁面自動 re-render |
| 3 | 日常工作即完成 | 一鍵化（派工/結案/上傳一鍵帶完所有相關資料），不要逐欄填表單 |
| 4 | 字體最小 18px | 全用 `--text-xs = 18px` 起跳，html base 16px。對應 design-tokens 規範 |
| 5 | oklch 配色 | 全 `oklch()`，hex 只當 `@supports not` fallback |

## 技術骨架

- 單檔 HTML（CLAUDE.md：雙擊瀏覽器即開、禁止 server）
- React 18 + React Router v6（CDN）
- Babel Standalone（瀏覽器內 JSX 編譯）
- D3.js v7（圖表、地圖）
- 中央 state：Context + useReducer + localStorage 持久化
- 配色：oklch + design-tokens
- 字級：18 / 20 / 24 / 28 / 32 / 48 / 56 px
- 字型：`-apple-system, "Microsoft JhengHei", "PingFang TC"`
