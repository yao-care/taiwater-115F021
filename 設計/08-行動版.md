# 08 — 行動版（React Native 風格）

## 實作方式

同一份 POC HTML 內用 React 元件模擬 RN UI（包在 phone frame container）。**真實可操作**：點按鈕真的會切換頁面、改 store、顯示通知。

## 行動版 React 元件清單

| 元件 | 對應 RN | 用途 |
|------|---------|------|
| `<PhoneFrame>` | — | 360×720 phone outline |
| `<StatusBar>` | StatusBar | 09:42 信號電池 |
| `<AppBar>` | Header | 標題列 + 返回 |
| `<TabBar>` | BottomTabNavigator | 底部 4 tab |
| `<StackNav>` | StackNavigator | 頁面切換動畫 |
| `<ListItem>` | FlatList Item | 任務卡片 |
| `<Card>` | View + Touchable | 通用卡 |
| `<FormInput>` | TextInput | 輸入框 |
| `<Button>` | TouchableOpacity | 按鈕 |
| `<Modal>` | Modal | 彈窗（拍照預覽） |

## 修漏員行動版（林文雄）

類似結構，主要差異：

- Tab：派工 / 地圖 / 實修登錄 / 統計 / 設定
- 「實修登錄」自動算欄位（挖填、漏水量、費用、監工照片）
- 「結案」一鍵 → 自動回客服 + 自動知會用戶

## 一鍵化邏輯範例

```jsx
function submitInspection(caseId) {
  const gps = mockGetGPS();         // 自動 GPS
  const photos = state.tempPhotos;  // 取拍好照片
  dispatch({
    type: 'SUBMIT_INSPECTION',
    payload: { caseId, gps, photos, timestamp: now() }
  });
  // store reducer 會：
  // 1. 更新 case.status
  // 2. 新增 inspection 紀錄
  // 3. 推通知給廠所
  // 4. 寫 audit log
  // 5. 重算區處 KPI
  navigation.goBack();
  toast('✓ 已上傳，廠所已收到通知');
}
```
