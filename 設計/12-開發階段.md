# 12 — 6 階段開發計畫

確認設計後依此順序動手。每階段完成後給你看，調整後再進下一階段。

## 階段 1：技術骨架（最重要）

- HTML + React 18 + Router + Babel CDN
- StoreContext + useReducer + localStorage
- design-tokens CSS（oklch）
- 共用元件：AppShell / Header / Nav / PageHeader / Toolbar / Button / Card / Table / KpiCard / Badge / Modal / Toast
- 初始化 mock 資料：50 案件 / 30 使用者 / 200 管段 / 14 介接 / 20 廠商

**驗收**：打開能看到 layout、有 demo 資料、style 對

## 階段 2：登入 + 11 角色 dashboard

- 登入頁（10 帳號下拉直達 + 真實演示模式）
- 11 個 dashboard（系統管理員、總處、區處、廠所、客服、DBA、資安、2 個稽核員）
- Nav 動態 filter
- 角色快切 widget

**驗收**：可以切換每個角色看到不同 dashboard

## 階段 3：流程 A 完整實作（案件生命週期跨角色）

- 客服「+ 新案件」
- 廠所派工看板（拖拉）
- 檢漏員行動版任務 → 拍照 → 上傳
- 修漏員行動版實修登錄
- 結案 → 回客服 → KPI 即時更新
- 跨角色通知連動

**驗收**：開兩個分頁切角色玩，看資料即時同步

## 階段 4：行動版完整 React Native UI

- PhoneFrame + StatusBar + AppBar + TabBar + Stack Nav
- 檢漏員 5 頁（任務 / 地圖 / 拍照 / 日報 / 設定）
- 修漏員 5 頁（派工 / 地圖 / 實修 / 統計 / 設定）
- 一鍵化邏輯（GPS 自動 / 照片自動 / 通知自動）

**驗收**：行動版可真實互動，不是靜態圖

## 階段 5：核心特殊功能

- D：年度成果報告書（16 章自動產生 + ODF 匯出）
- E：PCCES XML 編製 wizard（編碼正確率 40% 自動檢核）
- F：資安合規矩陣（12 構面 + SBOM + 第三方檢測 + 12 子類 + ISMS）
- G：介接管理（14 系統健康度 + WMTS/WMS toggle）
- 專案管理 dashboard（5 階段 Gantt + 罰則 + 團隊 + 教訓 + 文件中心 + 需求追溯）

**驗收**：六大流程都可玩，承辦看了會點頭

## 階段 6：補完剩餘 RFP 葉子

- 用通用版型自動產生剩餘 ~100 個葉子（CRUD/查詢/文件等）
- 確保 nav 中每個葉子都能點開看到對應畫面
- 加入 RFP 追溯標籤

**驗收**：完整對應 RFP 全部 126 葉子
