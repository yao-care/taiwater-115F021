## Header 共用元件

| 元件 | 行為 |
|------|------|
| 🔍 全域搜尋 | 跨模組搜尋：cases / users / pipes / docs。鍵入即時下拉建議 |
| 🏛 區處切換 | 13 區處下拉。切換後所有列表自動 filter（連動） |
| 🔔 通知 | 紅點計數。任一角色操作會通知對應角色（client / 廠所 / 主管） |
| 👤 使用者 menu | 個人設定 / 變更密碼 / 登出 |
| 🎭 角色快切 | POC demo 用：不登出即切換角色看效果（真實演示模式隱藏） |
| ⚙ 重置示範 | 清 localStorage、重新初始化 mock 資料 |

## Nav 依角色動態過濾

範例：

- **檢漏員**：只看到「今日任務 / 我的案件 / 工作日報 / 設定」（極簡，行動版優先）
- **廠所人員**：看到「派工 / 我的案件 / 工程預算書 / 廠商管理 / 報表」
- **資安人員**：看到「ISMS / SBOM / 弱掃 / 滲透 / 源碼 / 12 構面 / 稽核日誌」
- **系統管理員**：看到全部（除個人 dashboard 外）
