## 2. 7 條跨角色流程的落點

每條流程承辦可從任一切入點開始玩，所有資料即時連動（Store 集中 + useReducer dispatch + localStorage 持久化）。

| 流程 | 涵蓋角色 | 演示路徑（hash route） | 連動點 |
|------|---------|---------------------|--------|
| **A** 案件生命週期 | 客服→廠所→檢漏員→修漏員→客服→區處→總處 | `#/repair/dispatch` → `#/repair/cases/new` → `#/mobile/inspector` → `#/repair/cases/{id}` → `#/mobile/repairer` → `#/dashboard/case-track` 觀察 | cases / dispatches / inspections / repairs / notifications / auditLogs / kpi 連動 |
| **B** 行動版檢漏員一日 | 檢漏員 | `#/mobile/inspector` → 任務/地圖/拍照/日報 | cases / inspections / GPS / 照片 |
| **C** 廠所派工管理 | 廠所人員 | `#/repair/dispatch-board` 拖拉看板 | cases.status / dispatches |
| **D** 年度成果報告書 | 區處主管→總處 | `#/annual-report/16-chapter` → 自動產生 → ODF 匯出 | 從 cases / repairs / inspections 即時計算 16 章 |
| **E** PCCES 預算書 | 廠所人員 | `#/pcces/wizard` 5 步驟 | repairs / 工項編碼資料庫 / 編碼正確率檢核 |
| **F** 資安合規檢核 | 資安人員 + 內外稽核 | `#/security/matrix` → `#/security/access-control` → `#/security/sbom` | 同一份 ISMS / SBOM 矩陣，內外稽核唯讀視角 |
| **G** 介接系統管理 | 系統管理員 + DBA | `#/integration/health` → `#/integration/topology` | integrations 健康度 / 同步紀錄 |

**演示策略**：每條流程在對應子系統有「演示按鈕」（如 `[一鍵推進流程 A]`），點下後 dispatch 多個 action 模擬整條流程，承辦在 `#/dashboard/case-track` 看 timeline 即時更新。

## 8. UI / 互動風格細則

### 字級
- 全域最小 18px（`--text-xs`），絕對不縮小
- 行動版 phone frame 內字級不變（仍 ≥18px）
- 表格 dense 模式仍用 `--text-sm: 20px`

### 顏色
- 主色：台水深藍 `oklch(0.34 0.08 250)`
- 嚴重度：critical 紅 / high 橘 / medium 琥珀 / low 藍 / pass 綠
- 全 oklch，hex 僅 `@supports not` fallback

### 卡片密度
- 桌面：頁面外距 32px / 卡片間距 20px / 卡片內距 20-24px
- 行動版：phone frame 內 16px 內距

### 互動模式
| 場景 | 用 | 不用 |
|------|-----|------|
| 操作成功 / 失敗回饋 | Toast | alert / inline 訊息 |
| 確認 / 預覽 / 表單 | Modal | 跳新頁 |
| 派工 / 文件排序 | 拖拉（react-dnd 太重，用原生 HTML5 Drag API）| Modal 選單 |
| 頁面切換 | hash route（HashRouter）| reload |
| 跨角色通知 | NotificationCenter + Header bell | popup |
| 麵包屑 + RFP 章節 | 每頁顯示 | — |
| 表格排序 / filter | thead 點擊 / Toolbar filter | — |
| 「一鍵化」操作 | 單一按鈕 → 多 dispatch action | 多步驟表單 |

### 麵包屑規範
```
首頁 > [子系統] > [模組] > [葉子]    RFP 附錄一 X(Y) Z
```

例：`首頁 > 修漏子系統 > 派工管理 > 派工看板    RFP 附錄一 四(四)`
